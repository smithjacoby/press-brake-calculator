REFERENCE / HOW IT WORKS

Documentation

Calculator purpose, inputs, formulas, and operating sequence.

Purpose

This calculator provides the final X and Y/R values for the back gauge. It selects a normal or lifted paddle-clearance mode from the unrounded X calculation. It does not control or communicate with the press brake.

Inputs

  • Die Size: the die measurement used to calculate move back distance.
  • Piece Length: the total length of the material.
  • Bend Length: where along the piece the bend should be located.

Enter all measurements in inches.

How to use

  1. Follow the four setup steps on the Calculator tab.
  2. Enter all three measurements as finite numbers.
  3. Select Calculate or press Enter from an input field.
  4. For lifted mode, use Create Bend → Add Back Gauge; for normal mode, use the usual Move To workflow.

Machine setup sequence

  1. Home the punch and back gauge using the established procedure.
  2. Zero the back-gauge X and Y values after homing.
  3. Enter die size, piece length, and bend length.
  4. If lifted mode is active, choose Create Bend → Add Back Gauge and enter Final X in X and Final Y/R in R. For normal mode, use the usual Move To workflow.

The initial X home offset (--) is added to the final X value automatically. The normal Y / R offset (--) is used in normal mode; lifted mode adds 0.3755 before displaying the Final Y/R value.

Formulas and variables

Move Back Distance = Die Size / 2

Normal X = Initial X Home Offset + Piece Length - Bend Length - Move Back Distance - 1

Lifted X = Initial X Home Offset + Piece Length - Bend Length - Move Back Distance

For the current 1.18-inch test die, the calculator checks the unrounded normal X position against -15.746. Below that threshold, it lifts Y/R by 0.3755 and uses the front paddle reference, so the -1.000 paddle offset is not applied.

Rules and limitations

  • Use consistent units for every measurement and the fixed adjustment.
  • Die Size and Piece Length must be greater than zero.
  • Bend Length can be zero, but cannot exceed Piece Length.
  • For the current 1.18-inch test die, an unrounded normal X below -15.746 activates lifted clearance mode. The displayed lifted X may differ because it uses the front paddle reference.
  • This page only calculates a value; it does not verify machine compatibility, tooling, material, or setup suitability.
  • Machine-specific instructions must come from your established procedures.

Troubleshooting

  • Missing input: enter a value in every field.
  • Invalid number: use a finite numeric value; remove text or separators not supported by your browser.
  • Measurement range: ensure Die Size and Piece Length are positive and Bend Length does not exceed Piece Length.
  • Unexpected result: confirm consistent units and compare each breakdown value with the displayed formula.

MACHINE REFERENCE

Settings

Update the X offset and the normal Y/R value. The calculator raises Y/R by 0.3755 when lifted clearance mode is active.

The saved X offset is used in every calculation. The saved Y/R value is used for normal mode, and lifted mode adds 0.3755. Both are stored in this browser until you restore the defaults.
