REFERENCE / HOW IT WORKS

Documentation

Calculator purpose, inputs, formulas, and operating sequence.

Purpose

This calculator estimates the final X position from die size, total piece length, and bend location using the established formula shown here. It does not control or communicate with the press brake.

Inputs

  • Die Size: the die measurement used to calculate move back.
  • Piece Length: the total length of the material.
  • Bend Length: where along the piece the bend should be located.

Enter all measurements using the same unit system. The fixed adjustment of 1 uses that same unit.

How to use

  1. Follow the five setup steps on the Calculator tab.
  2. Enter all three measurements as finite numbers.
  3. Select Calculate or press Enter from an input field.
  4. Review the breakdown and final calculated X position before entering it into the machine.

Machine setup sequence

  1. Home the press brake using its established machine-specific procedure.
  2. Enter initial X -15.74600 and Y 1.34600 positions.
  3. Zero the machine according to its established operating procedure.
  4. Enter die size, piece length, and bend length.
  5. After zeroing, enter the displayed final calculated X position.

Initial positions are the fixed positions entered after homing. The final calculated X position is calculated from the current measurements. They serve different roles.

Formulas and variables

Move Back = Die Size / 2

X Position = Piece Length - Bend Length - Move Back - 1

The final subtraction of 1 is a fixed adjustment. No intermediate value is rounded before the final result is displayed.

Rules and limitations

  • Use consistent units for every measurement and the fixed adjustment.
  • Die Size and Piece Length must be greater than zero.
  • Bend Length can be zero, but cannot exceed Piece Length.
  • This page only calculates a value; it does not verify machine compatibility, tooling, material, or setup suitability.
  • Machine-specific instructions must come from your established procedures.

Troubleshooting

  • Missing input: enter a value in every field.
  • Invalid number: use a finite numeric value; remove text or separators not supported by your browser.
  • Measurement range: ensure Die Size and Piece Length are positive and Bend Length does not exceed Piece Length.
  • Unexpected result: confirm consistent units and compare each breakdown value with the displayed formula.
